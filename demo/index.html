ThanosFx

v0.1.0

WebGL effects for the DOM, with nothing to install.

Reduced motion is on — effects use a short opacity fade.

Zero dependencies · WebGL2 · TypeScript

Make the DOM disappear.

Capture any element, rasterize it to a texture, and animate it with GPU particles. Burn it, ripple it, shred it, shatter it, pixelate it, or put it back together.

Live examples

Six ways to say goodbye.

Every card is real DOM. Click it to run the effect, or open the playground to tune the shaders.

Quick start

One element in, dust out.

terminal 
npm install thanosfx
app.ts 
import { burn } from "thanosfx";

const card = document.querySelector<HTMLElement>(".card")!;

burn(card, { duration: 1700 }).promise.then(() => {
  console.log("gone");
});

Why it works

Small on purpose.

One texture, many effects

Every effect shares the same capture, overlay and render loop.

Real DOM, real pixels

Text, borders, gradients and images are captured as they render.

Zero runtime dependencies

WebGL2 and the browser do the work. No canvas library required.

Accessible by default

Reduced motion falls back to a short opacity fade.
